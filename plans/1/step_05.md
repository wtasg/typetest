# Step 05 — Typing surface and renderer

Goal: Render target text with per-character state and visible whitespace glyphs.

Tasks:

- Implement `TypingArea` and `TypingText` components.
- Render characters with states: untyped, current, correct, incorrect.
- Add visible glyphs for space/tab/newline with configurable symbols.
- Wire keystroke input to the engine API.

Deliverable: interactive typing surface with visible whitespace.
