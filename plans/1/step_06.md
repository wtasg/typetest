# Step 06 — Source management (paste/upload/select)

Goal: Allow users to add text sources by paste or file upload and select ranges.

- Allow selecting entire source or a character offset range.
- Materialize the selected target when starting a run.

Deliverable: source list UI and add/upload flows.
